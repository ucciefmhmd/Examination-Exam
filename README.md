# Examination System Database (SQL Server)

A **SQL Server** database for an online examination system: courses, instructors, students, question pools, exams and automatic grading. It was built as a team project during training.

## What's inside
| Folder | Contents |
|---|---|
| `1- Create Database`, `2- Create Tables` | Database and schema scripts |
| `3- Insert Data` | Seed data |
| `4- Views`, `5- Indexs` | Reporting views and indexes |
| `6- Procedure`, `7- Functions`, `8- Triggers` | Stored procedures, functions and triggers for the business logic |
| `9- Accounts` | Logins and role-based permissions |
| `10- Test Query`, `11- Backup` | Test queries and backup scripts |
| `12- Documentation` | ERD, table mapping and script documentation |
